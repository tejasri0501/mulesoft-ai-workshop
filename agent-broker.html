Module 4: Building the Agent Orchestration

The Broker acts as the "brain," routing requests between specialized agents.

Exercise: Setting up the Agent Broker

1. Create Agent Network:

1.1 Create a new Mule Project: Click on Mule logo in the left menu bar. Select Create an Agent Network and create new project with

Project Name: {initials}-a2a-server-listener
Business Group: anypoint-cbp122444(similar to this)

1.2 agent-network.yaml specifies brokers, agents, MCP servers, LLMs, policies, and authentication in your agent network. Replace existing agent-network.yaml with below configuration, make sure to replace <your-initials> in the below configuration with your initials 

schemaVersion: 1.0.0
label: <your initials>-inventory-contract-network
brokers:
   <your initials>-inventory-contract-broker:
       card:
           protocolVersion: 0.3.0
           name: <your initials>-inventory-contract-broker
           description: The broker allows us to get the inventory and contract details for a specified part.
           url: ${ingressgw.url}/<your initials>-inventory-contract-broker
           capabilities:
               pushNotifications: true
           version: 1.0.0
           securitySchemes: {}
           defaultInputModes:
               - application/json
               - text/plain
           defaultOutputModes:
               - application/json
               - text/plain
           skills:
               - id: inventory-contract
                 name: inventory-contract
                 description: Get the inventory and contract details for a specified part.
                 examples:
                     - Can you get me parts info for SFP-10G-T-CAT-AO and also contract information.
                 inputModes:
                   - application/json
                   - text/plain
                 outputModes:
                   - application/json
                   - text/plain
                 tags: [inventory-agent]
       spec:
           llm:
               ref:
                   name: google-gemini
               configuration:
                   model: ${googleGemini.modelName}
                   gemini:
                       temperature: 0.3
                       topP: 0.95
                       responseLogprobs: false
                       maxOutputTokens: 5000
           instructions:
               - if user is asking only for parts information. Fetch the inventory or part information using inventory-agent get all the necssary information,
                  if user is asking only for parts information and contract information once you fetch details inventory-agent if
                  using same part number call contract-mcp-server and get contract details.
           links:
               - agent:
                     ref:
                         name: inventory-agent
           tools:
               - mcp:
                     ref:
                         name: contract-mcp-server
agents:
   inventory-agent:
       label: inventory-agent
       metadata:
           protocol: a2a
           platform: agentforce
mcpServers:
   contract-mcp-server:
       label: contract-mcp-server
       metadata:
           transport:
               kind: streamableHttp
               path: /mcp
llmProviders:
   google-gemini:
       label: Google Gemini
       description: Google Gemini LLM Provider
       metadata:
           platform: Gemini
connections:
   inventoryAgentConnection:
       kind: agent
       ref:
           name: inventory-agent
       spec:
           url: ${inventory-agent.url}
   contractmMcpServerConnection:
       kind: mcp
       ref:
           name: contract-mcp-server
       spec:
           url: ${contract-mcp-server.url}
   google-gemini-connection:
       kind: llm
       ref:
           name: google-gemini
       spec:
           url: ${googleGemini.url}
           configuration:
               apiKey: ${googleGemini.apiKey}
               timeout: 600000

2. Configure exchange.json:

2.1 exchange.json specifies Anypoint Exchange assets that are referenced in your agent network, as well as the variables to use in your agent network. Just replace below metadata snippet in exchange.json, Important: Do not replace the complete exchange.json file. Also, replace the parameters marked in red with correct values based on previous deployments.

inventory-agent: CloudHub URL for deployed A2A Server
contract-mcp-server: CloudHub URL for deployed MCP server
apikey: Salesforce will be providing the key 
"metadata": {
   "variables": {
     "inventory-agent": {
       "url": {
         "description": "get inventory details from agentforce",
         "default": "replace with your URL/agentforce-agent",
         "secret": false
       }
     },
     "contract-mcp-server": {
       "url": {
         "description": "get contract details from salesforce",
         "default": "point to your mcp url",
         "secret": false
       }
     },
     "googleGemini": {
       "url": {
         "description": "Google Gemini API URL",
         "default": "https://generativelanguage.googleapis.com/",
         "secret": false
       },
       "modelName": {
         "description": "Google Gemini Model Name",
         "default": "gemini-2.5-flash",
         "secret": false
       },
       "apiKey": {
         "description": "Google Gemini API key",
         "default": "<gemini API Key here>",
         "secret": true
       }
     }
   }
 }

3. Publish Agent Network Assets to Anypoint Exchange:

3.1 Publish Agent Network Assets to Anypoint Exchange - This procedure builds and publishes your broker group to Anypoint Exchange - this is the registry & repository for all AI assets (MCP Servers, Agents, Agent Brokers) & integration assets (API's, connectors, integration applications & templates etc.)

3.2 In Anypoint Code Builder, open the Command Palette.

3.3 Select MuleSoft: Publish Agent Network Assets.

→

3.4 Enter asset version and click Publish

→

3.5 The broker group asset is published to Anypoint Exchange with the defined agent cards and external services (agents and MCP servers).

4. Deploy Agent Network:

4.1 In Anypoint Code Builder, open the Command Palette.

4.2 Select MuleSoft: Deploy Agent Network.

4.3 Enter the following information,

Environment: Sandbox
Deployment Target: google-private-space,
Ingress Gateway: agent-network-ingress-gw
Egress Gateway: agent-network-egress-gw

4.4 Click on Deploy

4.5 Your broker group project is deployed deployed and ready to be tested

4.6 All the Agent and MCP assets are now managed via API manager - it allows you to govern, manage and secure API's and AI assets

5. Executing the Agent Network:

5.1 Get the Ingress gateway URL for the broker - Ingress gateway protects your agent network by allowing you to apply governance policies

5.2 On Anypoint platform, select Runtime Manager

5.3 On the Runtime Manager page, select Flex Gateways → agent-network-ingress-gw

5.4 Copy the Public endpoint url

5.5 Append your agent broker name to the end of this url -

https://agent-network-ingress-gw-tb6jai.rioqsq.usa-e2.cloudhub.io/<your agent broker>
(for e.g. - https://agent-network-ingress-gw-tb6jai.rioqsq.usa-e2.cloudhub.io/pjsfdc-inventory-contract-broker)

5.6 Use the following curl command to invoke the agent broker,

curl --location 'https://agent-network-ingress-gw-tb6jai.rioqsq.usa-e2.cloudhub.io/hb-inventory-contract-broker/' \
--header 'Content-Type: application/json' \
--data '{
"jsonrpc": "2.0",
"id": 12345,
"method": "message/send",
"params": {
"message": {
"role": "user",
"kind": "message",
"parts": [
{
"kind": "text",
"text": "Can you get me parts info for SFP-10G-T-CAT-AO and contract information for the same?"
}
],
"messageId": "b69d3e84-7135-47f8-80be-7d0563913082"
},
"metadata": {}
}
}'

6. Troubleshooting & Notes:

6.1 Credentials: Ensure your Gemini API Key is stored as a secret in exchange.json. URLs: When deploying to CloudHub, always update your agent.host properties to match the newly generated public endpoint. Once a project is deployed , go to Anypoint platform -> login into your account -> click on Runtimes ->select environment -? select a2a-agentforce-agent project. Click on settings -> click on properties tab and add the following property agent.host=<Copy & Paste A2A Project URL> (For example, https://google-a2a-agentforce-agent-3ujrc9.5sc6y6-1.usa-e2.cloudhub.io ) (update this accordingly)
