Module 1: Building the Salesforce System API

In this exercise, you will build a Mule application that queries Salesforce for contract product details.

Exercise: Create the System API

1. Initialize Project:

1.1 Login to Anypoint Platform using your credentials as created during self-registration

1.2 Click on Get Started in Anypoint Code Builder section

1.3 Click on Launch button in Your Anypoint Code Builder Cloud IDE, this opens the Cloud IDE in new tab

1.4 Log in to Anypoint Platform for the Cloud IDE by clicking on the bottom right of the IDE

1.5 Select Develop an Integration from the left menu

1.6 Enter Project Name:

Project Name: {initials}-salesforce-contract-api

2. Logic Development:

2.1 Select Build a Flow and rename flow name to

Flow Name: get-contract-flow

2.2 Add an HTTP Listener:

2.2.1 Click on + in the flow path on the main canvas

2.2.2 Search for HTTP connector

2.2.3 Select Listener operation within the HTTP connector

2.2.4 Select Listener processor that was just added

2.2.5 Click on "+" sign next to Connection Config to add HTTP connector configuration

2.2.6 Enter the following HTTP configuration details:

Host: 0.0.0.0
Port: 8081

2.2.7 Enter http URI Path:

Path: /contract

2.3 Add the Salesforce Query processor by selecting ‘+’ under the ‘Listener’ component

2.3.1 Create a new Salesforce Connection

2.3.2 Configure credentials and click Apply
Note: Credentials will be provided by Salesforce team during workshop

2.3.3 Configure the SQL Query:

SELECT Contract_Price__c, Standard_Price__c, Contract__r.Status, Contract__r.ContractNumber, Contract__r.StartDate, Contract__r.EndDate
FROM Contract_Product__c WHERE Part_Number__c = ':partName'

2.3.4 Parameters:

Key: partName
Value: payload.partName

3. Add a Transform message:

3.1 Set the following dataweave expression:

%dw 2.0
output application/json
---
payload

4. Local Validation:

4.1 Select Run Mule Application to run the application locally

4.2 Confirm that the application has started successfully

4.3 Click on + sign in the terminal window to open a new terminal. Test via Terminal:

curl --location 'http://localhost:8081/contract' \
--header 'Content-Type: application/json' \
--data '{"partName": "SFP-10G-T-CAT-AO"}'

5. Deploy Application to CloudHub 2.0

5.1 Launch Command Palette by clicking on the gear wheel at the bottom left of the IDE

5.2 Type MuleSoft: Select Deploy to MuleSoft CloudHub

5.3 Select Business Group: anypoint-cbp-17695426 (different from below screenshot)

5.4 Select deployment target as CloudHub 2.0

5.5 Select any one of the Shared Spaces listed

5.6 Select deployment Environment as Sandbox

5.7 Click Deploy

5.8 Select runtime version as Java 17

5.9 Specify asset version as 1.0.0

5.10 Open Runtime Manager to verify that the application is deployed to CloudHub

5.11 Test final CloudHub request:

curl --location 'yourcloudhubURL/contract' \
--header 'Content-Type: application/json' \
--data '{"partName" : "SFP-10G-T-CAT-AO"}'
